# Project MCP для AI Challenge App

CRM использует существующий RAG исходного проекта через отдельный MCP-сервер.
Патч `support-mcp.patch` включает полные исходники команды `cmd/supportmcp`,
пакета `internal/supportmcp`, его тестов и документацию. Основное веб-приложение
запускать не требуется. Данные RAG, эмбеддинги и настройки доступа в патч не входят.

Патч подготовлен для [Desuzed/ai-challenge-app](https://github.com/Desuzed/ai-challenge-app)
на коммите `ae7f29e429194d8f4f8ed982c79a9a89e1ee0ce0`.
На Mac сохраните свои локальные изменения и в корне исходного проекта выполните:

```sh
git apply --check /path/to/support-crm/integrations/ai-challenge-app/support-mcp.patch
git apply /path/to/support-crm/integrations/ai-challenge-app/support-mcp.patch
go test ./internal/supportmcp
go build ./cmd/supportmcp
```

Если эти файлы уже установлены в проекте, повторно применять патч не нужно.
Для другой версии проекта сначала проверьте совместимость через `git apply --check`.
Фактический состав интеграции можно проверить командой `git apply --stat`.

Создайте штатный RAG-индекс проекта по его README и запустите сервис эмбеддингов
с той же моделью, которая использовалась при индексации. После этого:

```sh
export SUPPORT_MCP_TOKEN='случайный токен не короче 32 символов'
go run ./cmd/supportmcp -root . -addr 127.0.0.1:8091
```

В приватной конфигурации CRM `PROJECT_MCP_TOKEN` должен совпадать с этим токеном.
Через обратный SSH-туннель `PROJECT_MCP_URL=http://127.0.0.1:18091/mcp`
указывает на MCP-сервер Mac. Подробности туннеля и развёртывания находятся
в [основном README](../../README.md).

Сервер предоставляет чтение документов, поиск по RAG, проверку состояния индекса
и пять файловых инструментов: список, поиск по текущим файлам, чтение, сохранение
Markdown и предпросмотр diff. Файловый каталог и RAG указывают на `ai-challenge-app`:
обёртка CRM использует `--project-root`, ручной запуск — `-root`. При необходимости
`SUPPORT_FILES_ROOT=/absolute/path/to/ai-challenge-app` задаёт checkout явно. Если файлы прежней
интеграции уже установлены, обновите их из новой версии патча, затем пересоберите
`.local/support-project-mcp` и перезапустите его процесс.

Набор доступных файлов ограничен публичными исходниками и документацией;
приватные конфигурации, `.local`, сборки и символьные ссылки исключены.
Запись доступна для README.md, CHANGELOG.md и Markdown в docs/. Существующий
документ защищён проверкой SHA256; сервис возвращает фактический diff.
